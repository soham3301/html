    • ID Selector: #this-id, #main-header etc etc

  • Box Model

    The Box Model has Four Core Components

    1. Content:

      The innermost area where text, images, or child elements reside. Its sizing is targeted using the width and height properties

    2. Padding:

      The transparent space directly surrounding the content, sitting inside the element's border. It adds "breathing room" inside the background of the element

    3. Border:

      A visible or invisible line wrapped around the padding and content. You can customize its thickness, style, and color

    4. Margin:

      The transparent space outside the border that pushes adjacent elements away, creating visual separation between different boxes
